# reference/

参考资料：读来理解问题、做设计判断用，**不参与运行，也不进政策检索索引**。政策检索的语料在 `policy_docs/`。

可以放的内容，建议按子目录分：

| 子目录 | 内容 |
|---|---|
| `mimic/` | MIMIC 数据字典、表结构说明、使用笔记 |
| `papers/` | 相关论文（PDF 或笔记） |
| `cms/` | 不进检索语料的 CMS 资料、行业报告（如 OIG 报告、CMS-0057-F） |
| `examples/` | 外部格式示例（如 Da Vinci PAS） |

- 每份资料写明来源（URL）和获取日期，可以写在同目录的 `SOURCES.md` 里。
- 这里的内容不是设计依据。设计依据只有 `plan/snf_pa_consensus_work_plan_1025.md`；政策判断以 `policy_docs/` 的原文为准。
