### 3.2 年份规则不确定，而且影响队列规模

MIMIC 的日期整体平移过，真实年份只能从 `anchor_year_group`（3 年一组）推算，有 ±2 年误差。"入院年份 2011–2018"可以有几种写法。下表是 Medicare、≥65、存活、有出院小结时各去向的住院数 / 病人数：

| 年份规则 | SNF | HHC | HOME | REHAB |
|---|---|---|---|---|
| A 严格：真实年份一定落在 2011–2018（组起点+偏移 ≥ 2011，且组终点+偏移 ≤ 2018） | 15,795 / 10,483 | 17,308 / 10,937 | 16,335 / 11,053 | 2,657 / 2,297 |
| B 宽松：按组起点估算的年份在 2011–2018 | 21,624 / 14,477 | 24,688 / 15,614 | 22,913 / 15,330 | 3,833 / 3,353 |
| C `anchor_year_group` ∈ {2011–13, 2014–16, 2017–19} | 15,778 / 11,355 | 17,579 / 12,107 | 17,045 / 11,983 | 3,218 / 2,841 |
| 不限年份 | 30,613 / 19,444 | 34,157 / 20,250 | 32,558 / 20,450 | 5,501 / 4,711 |

设计 3.2 写"SNF……满足上述条件的约 3 万例"，但 30,613 是**不加年份限制**时的数。加上 2011–2018 后只有约 1.6–2.2 万例，设计文档这句需要改（见问题 5）。任何一种规则下，抽 dev 100 / test 200 都绰绰有余。

- 表与列白名单（问题 4）：
